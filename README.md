# PWSConsoleSite

Public website for PWS Console.

## Hosting

The site is deployed from GitHub `main` to Cloudflare Workers Static Assets.

Production: https://pwsconsole.com

## Local preview

Because the site is static, any basic local web server can preview it. Opening `index.html` directly also works for visual inspection, though root-relative navigation is best tested through a local HTTP server.
