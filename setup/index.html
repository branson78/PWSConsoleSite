Getting Started

Setup

PWS Console works without a personal weather station. PWS owners can optionally connect their own Weather Underground station.

Local Weather

Allow location access for current local weather and radar. A five-digit ZIP can be configured as a fallback location.

Optional Personal Weather Station

  • Use your own Weather Underground Personal Weather Station identifier.
  • Provide your own Weather Underground API key.
  • The API key remains stored in the iPhone Keychain.
  • Widgets and Apple Watch receive normalized station data, not the API key.
