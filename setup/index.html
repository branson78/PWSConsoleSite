Getting Started

Setup

PWS Console works with or without a personal weather station. Local Weather and radar can use your device's current location, and connecting a compatible personal station is optional.

Location & Local Weather

PWS Console uses device location for Local Weather and to center radar on your current area. If current location is unavailable and you have configured a ZIP code, PWS Console can use that ZIP code as a fallback location.

You can change or revoke location permission at any time through Apple device Settings. Removing Station configuration does not prevent Local Weather or radar from using your location or ZIP fallback.

Fire TV

PWS Console for Fire TV is ready to use without a PWS Console account or sign-in. In the app, enter a Home ZIP Code to set the approximate location used for weather, radar, forecasts, and alerts.

Fire TV does not use GPS or request a Fire TV location permission; your Home ZIP Code is its location source. See PWS Console for Fire TV for the big-screen experience and the Fire TV Privacy Policy for details.

Remote basics

  • Use the directional pad to move between controls.
  • Press Select to activate the focused control.
  • Press Back to return through the app's navigation; from the starting view, Back exits the app.

Connect Your Personal Weather Station

Connecting a personal weather station is optional. If your station already publishes observations through Weather Underground, you can configure it in PWS Console Settings on the iPhone.

  • Station ID is your Weather Underground Personal Weather Station identifier.
  • API Key is the API key associated with your own Weather Underground account.

If you need help locating your Station ID or obtaining an API key, visit Weather Underground. PWS Console documents its own integration; station hardware, calibration, networking, and publishing setup remain with your station manufacturer or Weather Underground.

Your API key is stored securely in the iPhone Keychain. It is never distributed to widgets, Apple Watch, or complications. After saving the Station configuration, use Refresh to retrieve your station observations.

Apple Watch

PWS Console supports both Station and Local Weather on Apple Watch. Station weather originates from the PWS configured on the paired iPhone, while Local Weather can use the Watch's native location and weather capabilities.

For the smoothest setup, open and configure PWS Console on the iPhone first, then open the Watch app. Personal Station configuration and credentials remain on the iPhone.

Widgets & Complications

Widgets and complications provide at-a-glance weather information. Station widgets receive the latest canonical Station information from the iPhone and never receive your Weather Underground API key.

Apple Watch complications can present Station or Local Weather according to the selected source. Apple controls background update timing, so a new update may not always appear immediately.

Refreshing Weather Data

PWS Console normally updates weather automatically. Refresh requests an immediate update. On Apple Watch, Refresh updates available Watch weather sources and helps synchronize current Station information from the paired iPhone.

When a weather source is temporarily unavailable, PWS Console may continue showing usable recent information while it attempts to recover.

Changing Your Configuration

Station configuration remains optional. You can change your Station ID, Weather Underground API key, ZIP fallback, and related preferences through PWS Console Settings.

Removing Station configuration disables that optional source; Local Weather and radar continue to work independently.

Need Help?

Visit Support or email support@pwsconsole.com. A useful problem report identifies the affected device or feature and describes what happened.

Never send your Weather Underground API key, passwords, or other credentials in support email or screenshots.
