Privacy

This is the public privacy-policy destination. Final policy language will be completed before production App Store distribution.

Privacy by architecture

PWS Console is designed so a user-owned Weather Underground credential remains on the user's iPhone in Keychain storage. It is not distributed to widgets, Apple Watch, complications, or the public PWS Console website.

Public website

This website is served as static assets through Cloudflare. It has no login, database, PWS credential handling, or connection to the private PWS Console application runtime.
